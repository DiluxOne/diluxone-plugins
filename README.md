# DiluxOne Plugins

The DiluxOne plugin catalog. Add it once and install any of its plugins.

## Claude Code

```
/plugin marketplace add diluxone/diluxone-plugins
```

Then install the plugins you want:

```
/plugin install diluxone-mermaid@diluxone
```

New plugins added to this catalog show up for everyone who already added it. To update: `/plugin marketplace update diluxone`.

## Plugins

| Plugin | What it does | Repo |
| --- | --- | --- |
| `diluxone-mermaid` | Create, edit and validate mermaid diagrams that never break: lint, the real mermaid 10, 11 and 12 parser, render geometry and visual review. | [diluxone/diluxone-mermaid](https://github.com/diluxone/diluxone-mermaid) |

## Other tools

Each plugin lives in its own repo with its own installation instructions, including Claude Desktop, claude.ai and a standalone CLI where available.
